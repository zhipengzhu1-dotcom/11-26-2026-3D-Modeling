# Model assets stay out of this public repo

The character model (【原神】沃雅妮莎, provided by miHoYo, converted by 观海) forbids redistribution and commercial use, and this repository is public. The model files, textures and everything derived from them (converted meshes, the Simulation Body, edited textures) are never committed to it; the repo holds only scripts and docs that rebuild those assets from a locally downloaded copy. Renders and videos made from the model must carry the full credit list.

A private copy kept as a backup is not redistribution. Where that copy lives, and the rule that it is never made public or shared, is in `0006-kept-results-live-outside-and-are-backed-up-privately.md`.
